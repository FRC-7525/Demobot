# DEMOBOT SETUP GUIDE:
Hey chat! This guide is made to help you get setup with the DEMOBOT even if you have **0** Controls experience.

I assume you have a windows laptop (hopefully a driver station or at least a team laptop). Make sure it is connected to wifi.

## Step 1:
Press the windows key on the keyboard to open the start menu. Open up the app named 2026 WPILIB VS Code. (Search for it)

## Step 2:
In the top left corner go to file and then New Window. Close the previous window and in the new window click on the button that says Clone Github Repository.

## Step 3:
Copy the url below and paste it into the little box that popped up:

## Step 4:
Hit enter and wait for like 2 minutes.

## Step 5:
Press *Ctrl + Shift + P* and type Build. Then, select the option reading "WPILIB: Build Robot Code". Ensure you get a message reading Build Successful.

## Step 6:
Power on the robot! Wait a minute for the robot to boot up and then connect to the WIFI Network labeled Demobot. The password is Team7525. 

## Step 7:
Press the windows key and open the app called FRC Driver Station. It should automatically connect after a moment and you should be able to see 3 green lights here. It may take a bit.

## Step 8:
Elastic Dashboard will have opened up when when you oppened the driver station. 

## Step 7:
Press *Ctrl + Shift + P* and type Deploy. Then, select the option reading "WPILIB: Deploy Robot Code". This may take a while. If it is taking over 4 minutes click in the terminal and press *Ctrl + C* and try deploying again.
